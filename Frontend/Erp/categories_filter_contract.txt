1. COMO O FILTRO FUNCIONA NO CODIGO
---------------------------------------------------------------------
ProductFilterDto (record):

    public record ProductFilterDto(
            String category,            // ANTIGA: ainda IGNORADA
            Marketplace marketplace,
            Boolean hasListings,
            StockFilter stock,
            String searchTerm,
            List<UUID> categoryIds      // NOVA: consumida pelo Specification
    )

Fluxo no service (getProductsPage):

    List<Long> categoryIdsInternal =
        (filterDto.categoryIds() == null || filterDto.categoryIds().isEmpty())
            ? List.of()
            : categoryRepo.findIdsByPublicIdsAndTenantId(
                  filterDto.categoryIds(), tenantId);
    ...
    if (!categoryIdsInternal.isEmpty()) {
        predicates.add(existsCategory(root, query, cb, categoryIdsInternal));
    }

existsCategory = EXISTS (
    SELECT id FROM Products
    JOIN categories (INNER JOIN via product_categories)
    WHERE product = corrente AND category.id IN (categoryIdsInternos)
)

Semantica:
  - Selecao multipla de categorias = OU (produto em QUALQUER uma delas).
  - Sempre limitado ao tenant do token (categories e por tenant;
    a resolucao acontece NO service, na conversao public_id -> id).
  - Combinavel com searchTerm / marketplace / hasListings / stock
    (todos os predicados via AND).


2. PARAMETRO DE ENTRADA
---------------------------------------------------------------------
Param          Tipo      Default  Descricao
categoryIds    UUID               Lista de public_id da tabela
                                  categories. REPEATIVEL (uma
                                  entrada por UUID, assim:
                                     ?categoryIds=<uuid1>&categoryIds=<uuid2>
                                  Ordem nao importa; duplicados
                                  contam uma vez na consulta (IN).
category       string    -        LEGADO (desatualizado): e aceito,
                                  mas NAO e consumido pelo service
                                  (nenhum predicate usa). NAO
                                  enviar no frontend.

O valor e o public_id (UUID), NAO o id interno (BIGINT). A conversao
public_id -> id acontece no service, com escopo do tenant
(findIdsByPublicIdsAndTenantId).

Regras de `categories`:

    (ver GAP A).

    ?categoryIds= (round-trip fechado).
